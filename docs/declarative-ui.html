3.4 声明式 UI

声明式 UI 是 UICornerstone 的核心工作流：用 JSON 描述控件树、布局、事件与主题，运行时由 LayoutParser 解析构建控件树。界面结构一目了然、可热重载、可被外部工具生成。

3.4.1 声明式 UI 介绍

一个布局文件描述整个界面：

{
  "version": "1.0",
  "viewport": { "width": 800, "height": 480 },
  "theme": {
    "fonts": { "default": { "name": "HarmonyOS_Sans_SC_Regular", "size": 16 } },
    "colors": { "background": "#282828FF", "text": "#FFFFFFFF" }
  },
  "controls": [
    {
      "type": "button", "id": "submitBtn",
      "rect": { "x": 280, "y": 140, "w": 100, "h": 35 },
      "caption": "Submit",
      "events": { "onClick": "handleSubmit" }
    }
  ]
}

通用节点键

键说明
type控件类型（kebab 小写）：label / button / edit-box / check-box / combo-box / numeric-up-down / progress-bar / scroll-bar / color-picker / text-area / panel / menu-bar / win-frame / splitter
id全局唯一标识，供 FindControl / findControlById 查找
rect{"x","y","w","h"}；支持百分比字符串（"50%"）
scale{"x":1.0,"y":1.0} 本地缩放
visible / enabled可见 / 启用
margin{"left","top","right","bottom"}
colors状态色对象：{"background":{"normal","hover","pressed","disabled"}}，含 text / border / textShadow / 控件特有键
events{"onClick":"handlerName"} 引用已注册处理器
children子控件数组（容器类型）

颜色格式："#RGB" / "#RRGGBB" / "#RRGGBBAA"，或 {"r":255,"g":0,"b":0,"a":128}。

加载与事件绑定

// C ABI
UICornerstone_RegisterAction(g_inst, "handleSubmit",
    [](UIControlHandle ctl, void* user){ /* ... */ }, NULL);
UICornerstone_LoadLayout(g_inst, LAYOUT_JSON);   // 或 LoadLayoutFromFile

// C++ Binding
ui->RegisterAction("handleSubmit", [](Control ctl){ /* ... */ });
ui->LoadLayout(layoutJson);
未注册的 handler 名会被静默跳过，便于同一布局文件在不同工程中复用。

3.4.2 声明式 UI 的布局

布局由面板的 layout 键启用，四种引擎：

流式（h-flow / v-flow）

"layout": { "type": "h-flow", "gap": 4,
             "padding": { "left": 4, "top": 4, "right": 4, "bottom": 4 } }

子控件以 flowWeight 弹性分配剩余空间（>0 弹性，0/缺省为固定尺寸）。

{
  "type": "panel", "id": "formPanel",
  "rect": { "x": 50, "y": 112, "w": 400, "h": 200 },
  "layout": { "type": "v-flow", "gap": 8 },
  "children": [
    { "type": "edit-box",  "id": "nameEdit", "flowWeight": 1, "rect": { "w": 0, "h": 30 } },
    { "type": "button",    "id": "submitBtn","rect": { "w": 100, "h": 35 } }
  ]
}

锚点（anchor）

"layout": { "type": "anchor" }
// 子控件：
{ "type": "button", "id": "okBtn",
  "rect": { "w": 100, "h": 32 },
  "anchor": "TOP_RIGHT",
  "anchorOffset": { "left": 10, "top": 10, "right": 0, "bottom": 0 } }

锚点值：TOP_LEFT / TOP_CENTER / TOP_RIGHT / MID_LEFT / CENTER / MID_RIGHT / BOTTOM_LEFT / BOTTOM_CENTER / BOTTOM_RIGHT / TOP_STRETCH / BOTTOM_STRETCH / LEFT_STRETCH / RIGHT_STRETCH / FILL。

网格（grid）

"layout": {
  "type": "grid",
  "columns": ["1fr", "2fr", "100px"],
  "rows": ["30px", "1fr", "auto"]
}
// 子控件：
{ "type": "button", "id": "cellBtn",
  "grid": { "row": 0, "col": 1, "rowSpan": 1, "colSpan": 1 } }

行列尺寸支持 Fixed（"100px"） / Flex（"1fr"） / Auto（"auto"） 三种。

重排时机：Panel::setRect() 与窗口 resize 自动触发 reflowChildren()；visible==false 的子控件被跳过。

3.4.3 声明式 UI 的组件逻辑

通过 components 定义可复用组件模板，在 layouts 中实例化：

{
  "components": {
    "SearchBar": {
      "props": { "placeholder": "Search...", "btnText": "Go" },
      "template": {
        "type": "panel", "layout": { "type": "h-flow", "gap": 4 },
        "children": [
          { "type": "edit-box", "id": "$search", "rect": { "w": 200, "h": 30 },
            "placeholder": "$props.placeholder" },
          { "type": "button", "id": "$go", "rect": { "w": 60, "h": 30 },
            "caption": "$props.btnText", "events": { "onClick": "onSearch" } }
        ]
      }
    }
  },
  "layouts": [
    { "use": "SearchBar", "id": "topSearch",
      "props": { "placeholder": "输入关键词", "btnText": "搜索" },
      "rect": { "x": 20, "y": 20, "w": 300, "h": 40 } }
  ]
}
组件系统会将组件中的控件（$id 形式）实例化到 layouts 数组指定的布局中；事件处理器同样经 RegisterAction 注册。

// C++（直接 API 的 LayoutParser）
parser.registerHandler("onSearch", [](shared_ptr ctl){
    auto edit = ctl->findControlById("topSearch_search");
    printf("search: %s\n", edit->getStringProperty("text").c_str());

3.4.5 主题样式

顶层 theme 键提供全局默认样式，控件节点上的显式键优先。应用顺序：主题默认 → 公共 colors → 控件专用颜色 → 控件专用字体。

"theme": {
  "colors": {
    "background": "#282828FF",
    "text": "#FFFFFFFF",
    "border": "#808080FF",
    "button": {
      "bg":    { "normal": "#3C3C3CFF", "hover": "#4C4C4CFF", "pressed": "#2C2C2CFF" },
      "border":{ "normal": "#505050FF" },
      "text":  { "normal": "#FFFFFFFF" }
    },
    "checkbox": { "check": "#66BB6AFF", "cross": "#FF5722FF", "boxBorder": "#53535AFF" },
    "progressbar": { "progress": "#66BB6AFF", "track": "#333333FF" }
  },
  "fonts": {
    "default": { "name": "HarmonyOS_Sans_SC_Regular", "size": 16 },
    "button":  { "size": 16 }
  }
}

支持类别（category）：button / label / editbox / textarea / checkbox / progressbar / panel / scrollbar / menubar；字体未定义时回退 default，再回退内置默认（HarmonyOS Sans SC Regular 16）。

3.4.6 热加载

HotReloader 监视布局文件，改动即热重载，无需重启程序：

// 文件变化 → 完全重建控件树（Handler 保留）
HotReloader reloader("layouts/main.json", [](){
    // 重建逻辑：removeAllControls → parseLayoutFile → addControl
});
reloader.poll();      // 每帧调用，默认 30 帧检查一次（≈0.5s）
reloader.reload();    // 或手动触发
reloader.setPollInterval(15);   // 调整检查间隔（帧数）
热重载会重建整棵控件树：控件状态（选中、输入内容）不保留；仅支持单文件轮询监视。适合开发期调整布局/样式。
