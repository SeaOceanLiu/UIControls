3 从基础入门

3.1 使用 C++ Binding 搭建

C++ Binding（binding/）是推荐的上手方式：它把 C ABI 包装成现代 C++ 接口，且纯动态加载——只链接 kernel32，运行时用 LoadLibrary 加载核心 DLL，不产生静态链接耦合。

3.1.1 CMake 集成

在你的工程中 add_subdirectory(binding) 并链接 UICornerstone_binding：

add_subdirectory(${UICORNERSTONE_ROOT}/binding)
target_link_libraries(myapp PRIVATE UICornerstone_binding)

运行时将 build/xxx_dll/UICornerstone.dll（或 libUICornerstone.so）放到可执行文件旁，或通过 Config.WithCoreLibraryDir(...) 指定搜索路径。

3.1.2 核心头文件

头文件内容
binding/include/UICornerstone.h入口类 UICornerstone::UICornerstone：实例创建、窗口、主循环、控件工厂（Create*）
binding/include/Control.h控件代理类 Control：统一属性读写（Set/Get）与回调注册
binding/include/Event.h事件类 Event：具名访问器（GetValueChanged / GetTextChanged 等）
binding/include/PropertyNames.h属性名与事件名字符串常量（kCaption / kEventClick 等）

3.1.3 最小 Hosted 模式应用

#include "UICornerstone.h"
#include "Control.h"
#include "Event.h"
#include "PropertyNames.h"

int main() {
    auto ui = UICornerstone::UICornerstone::Create(
        UICornerstone::UICornerstone::Config{}
            .WithBackend("sdl3")          // "sdl3" / "sfml" / "raylib"
            .WithWindow("My App", 800, 600));
    if (!ui) return 1;                    // DLL 缺失或路径错误 → nullptr

    auto button = ui->CreateButton("Click Me", 20, 20, 140, 36);
    auto label  = ui->CreateLabel("Hello", 20.0f, 20, 70, 220, 40);

    button.SetCallback(PropertyNames::kEventClick, [&](const Event&) {
        label.SetString(PropertyNames::kCaption, "Clicked!");
    });

    return ui->Run([](double dt) { (void)dt; });   // Hosted：UI 托管主循环
}
工厂方法对应 C ABI 创建函数：CreateButton(text,x,y,w,h)、CreateLabel(text,fontSize,x,y,w,h)、CreateCheckBox(text,x,y,w,h)、CreateEditBox(x,y,w,h)、CreateProgressBar(x,y,w,h)、CreateImage(image,x,y,w,h) 等。

3.2 创建你的第 1 个 UICornerstone 应用

在 3.1 的骨架基础上，本节用一个完整例子展示：控件工厂、属性读写、回调、主循环两种模式。

3.2.1 界面

  • 一个按钮「Toggle」：点击后切换标签可见性并累计计数；
  • 一个进度条：每帧推进，模拟加载；
  • 一个输入框：实时把文本镜像到标签。

3.2.2 代码

#include "UICornerstone.h"
#include "Control.h"
#include "Event.h"
#include "PropertyNames.h"
using namespace UICornerstone;

int main() {
    auto ui = UICornerstone::Create(
        UICornerstone::Config{}.WithBackend("sdl3").WithWindow("First App", 480, 320));
    if (!ui) return 1;

    int count = 0;

    // 控件工厂
    auto label  = ui->CreateLabel("Counter: 0", 18.0f, 20, 20, 240, 36);
    auto edit   = ui->CreateEditBox(20, 70, 280, 34);
    auto button = ui->CreateButton("Toggle", 20, 120, 120, 36);
    auto bar    = ui->CreateProgressBar(20, 180, 280, 24);

    // 事件回调（Event 具名访问器）
    button.SetCallback(PropertyNames::kEventClick, [&](const Event&) {
        bool vis = label.GetBool(PropertyNames::kVisible);
        label.SetBool(PropertyNames::kVisible, !vis);
        label.SetString(PropertyNames::kCaption, "Counter: " + std::to_string(++count));
    });
    edit.SetCallback(PropertyNames::kEventTextChanged, [&](const Event& e) {
        label.SetString(PropertyNames::kCaption, "Edit: " + e.GetTextChanged());
    });

    // 主循环：Embedded 模式（用户托管）
    float progress = 0.0f;
    while (!ui->IsQuitRequested()) {
        ui->ProcessEvents();
        progress += 0.003f;
        if (progress > 1.0f) progress = 0.0f;
        bar.SetFloat(PropertyNames::kValue, progress * 100.0f);
        ui->Update(1.0 / 60.0);
        ui->Clear();
        ui->Render();
        ui->Present();
    }
    ui->Shutdown();
    return 0;
}

3.2.3 两种主循环模式

模式适用场景写法
HostedUI 自行管理窗口与循环，业务在回调中做ui->Run([](double dt){ ... })
Embedded你的游戏/工具已有主循环，UI 嵌入其中while(!ui->IsQuitRequested()){ ProcessEvents → Update → Clear → Render → Present }

Embedded 模式可插入任意时刻：游戏帧内先 ProcessEvents() 喂输入，逻辑后 Update(dt)，渲染前 Clear/Render/Present。详见 第 7 章：嵌入到你的逻辑回路中。
