4.25 StatusBar（状态栏）

VSCode 风格底部状态栏：左右对齐的「段」，每段可显示文本/图标（任意控件），可点击（回调或弹出 MenuPanel 菜单）。继承链：StatusBar → ControlImpl → Control。设计文档见 design/StatusBar_Design.md。

4.25.1 控件的创建

// C++
auto bar = StatusBarBuilder(nullptr, SRect(0, 876, 1400, 24))
               .addStatusItem("branch", u8"main", false)
               .addStatusItem("enc", u8"UTF-8", true).build();

// C ABI
UIControlHandle bar = UICornerstone_CreateStatusBar(g_inst, 0, 876, 1400, 24, 1, 1);
UICornerstone_StatusBarAddItem(g_inst, bar, "branch", u8"main", 0);

// JSON
{ "type": "status-bar", "rect": [0, 876, 1400, 24], "fontSize": 13,
  "items": [ {"id": "branch", "text": "main"},
             {"id": "enc", "text": "UTF-8", "align": "right"} ] }

4.25.2 控件的属性

属性/字段类型默认值说明
fontSizeFloat13段文字字号
itemHeightFloatrect 高段高
items[].alignEnumleftleft / right
items[].icon资源引用—段图标（任意控件/Actor）
items[].menuMenuPanel id—点击弹出菜单

4.25.3 控件的回调 / 事件

事件名触发时机说明
items[].onClick点击无菜单段回调/动作
图标槽几何居中（内容无关基准）；文字型图标受字体基线偏移影响，建议用 Shape 等几何内容。弹窗菜单点击项自动关闭；外部点击/Esc 关闭为后续增强。
