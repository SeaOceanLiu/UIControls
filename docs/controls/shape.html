4.24 Shape（形状）

Shape 纯绘制控件：七种图元（rect/filled-rect/round-rect/circle/ellipse/polyline/polygon，空心与环带），支持多图元组合（单控件拼合复杂图形）与背景色。无事件/无子控件。继承链：Shape → ControlImpl → Control。设计文档见 design/Shape_Design.md。

4.24.1 控件的创建

// C++
auto s = ShapeBuilder(nullptr, SRect(40, 40, 90, 90))
             .setShape(ShapeType::Circle).setFillColor({59,130,246}).build();
// 多图元（组合图形）
s->addPrimitive(ShapeType::Polygon, SRect(0,0,150,52));

// C ABI
UIControlHandle s = UICornerstone_CreateShape(g_inst, 40, 40, 90, 90, 1, 1);
UICornerstone_ShapeAddPrimitive(g_inst, s, "circle", 10, 10, 40, 40);

// JSON
{ "type": "shape", "rect": [40, 40, 90, 90], "shape": "circle",
  "fill": "#3B82F6", "stroke": "#1E293B", "lineWidth": 2 }

4.24.2 控件的属性

属性/字段类型默认值说明
shapeEnumrectrect/filled-rect/round-rect/circle/ellipse/polyline/polygon
fillColor透明填充色（透明=空心）
strokeColor黑描边色
lineWidthFloat1描边宽（0=无）
radiusFloat0圆角半径（round-rect）
ringWidthFloat0环带宽（circle/ellipse）
points[{x,y}]—折线/多边形顶点（本地坐标）
primitivesArray—多图元组合（非空替代单图元）
colors.backgroundColor透明控件背景色（设后取消透明）

4.24.3 控件的回调 / 事件

事件名触发时机说明
—纯绘制控件，无事件—
缩放：绘制/命中均随 xScale/yScale 等比（2.0x 对照已验收）；空心圆描边闭合；凹多边形耳切三角化。mapToDrawPoint 提供本地→绘制坐标映射。
