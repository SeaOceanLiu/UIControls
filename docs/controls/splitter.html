4.18 Splitter（分割条）

Splitter 是可拖拽的分割条：关联两侧 sibling 控件，拖拽时实时调整两侧尺寸，支持最小尺寸约束与分割比例。继承链：Splitter → ControlImpl → Control。

4.18.1 控件的创建

// C++
Splitter(Control* parent, const SRect& rect, float xScale = 1.0f, float yScale = 1.0f);
SplitterBuilder(parent, SRect(244, 60, 6, 200))
    .setOrientation(false)              // false=垂直分割（左右分栏）
    .setLinkedControls(firstPanel, secondPanel)
    .setSplitRatio(0.4f).build();

// C ABI
UIControlHandle sp = UICornerstone_CreateSplitter(g_inst, 244, 60, 6, 200, 1 /*orientation*/);

// JSON
{ "id": "mySplitter", "type": "splitter",
  "rect": { "x": 244, "y": 60, "w": 6, "h": 200 },
  "orientation": "vertical",
  "firstPanel": "panelFirst", "secondPanel": "panelSecond",
  "thickness": 6, "ratio": 0.4, "minFirst": 50, "minSecond": 50,
  "events": { "onSplitterMoved": "onSplitterMoved" } }
JSON 中 orientation: "vertical" → 垂直分割（左右分栏），其余为水平；rect 可省略，由 first/second 控件边界自动推导。Splitter 节点必须排在关联面板之后。

4.18.2 控件的方法

方法说明
create() / draw() / handleEvent(Event) / setRect(SRect)生命周期与绘制 / 事件 / 位置
setOrientation(bool horizontal) / isHorizontal()方向：true=水平分割（纵向分栏），false=垂直分割（横向分行）
setLinkedControls(first, second)关联两侧 sibling 控件
setFirstControl(...) / setSecondControl(...)单独设置一侧
getFirstControl() / getSecondControl() / clearLinkedControls()查询 / 解除关联
setMinSize(firstMin, secondMin) / getMinFirst() / getMinSecond()两侧最小尺寸（默认 20）
setThickness(float) / getThickness()分割条厚度（默认 H=4 / V=6）
setSplitRatio(float) / getSplitRatio()分割比例（0~1，first 占比；set 即触发回调）
setColor(normal, hover, drag) / 三个 getter三态颜色（默认 #808080 / #4A90D9 / #3A80C9）
setOnSplitterMoved(OnSplitterMovedHandler)拖拽结束回调
setColorProperty / setBoolProperty / setFloatProperty / setPtrProperty（+getter）、setCallbackProperty属性系统分发

4.18.3 控件的属性

属性类型默认值说明
ratioFloat0.5分割比例（set→setSplitRatio；get 别名 value）
thicknessFloat4 / 6分割条厚度
first-min / second-minFloat20两侧最小尺寸（get 别名 range-min / range-max）
edge-marginFloat—同时设置 minFirst 与 minSecond
horizontalBool—true=水平分割
line / line-hover / line-dragColor灰 / 蓝 / 深蓝三态颜色
first-linked / second-linkedPtrnull关联控件句柄（setPtrProperty）

4.18.4 控件的回调

回调 / 事件名触发时机负载
setOnSplitterMoved(handler)（C ABI 事件 moved；JSON 键 onSplitterMoved）拖拽结束（endDrag）及 setSplitRatio 后void(shared_ptr<Splitter>, float ratio)

4.18.6 C++ Binding 样例

auto splitter = ui->CreateSplitter(244, 60, 6, 200, 1 /*orientation*/);
splitter.SetFloat(PropertyNames::kRatio, 0.4f);
splitter.SetFloat(PropertyNames::kThickness, 6.0f);
splitter.SetCallback(PropertyNames::kEventMoved, [](const Event& e) {
    printf("ratio = %.3f\n", e.GetMovedPosition());
});
// 关联控件经 "first-linked" / "second-linked" 属性或 AddChild 顺序管理
