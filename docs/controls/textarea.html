4.19 TextArea（多行文本输入）

TextArea 是多行文本输入控件：按 \n 分行 + 自动换行（word wrap）、垂直 / 水平内置滚动条、光标与选区、剪贴板（Ctrl+C/V/X）。继承链：TextArea → EditBox → ControlImpl → Control（继承 EditBox 全部文本能力）。

4.19.1 控件的创建

// C++
TextArea(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
TextAreaBuilder(parent, SRect(750, 360, 200, 100), 2.0f, 2.0f)
    .setText("2x scaled TextArea").setWordWrap(true).setLineHeight(22).build();

// C ABI
UIControlHandle ta = UICornerstone_CreateTextArea(g_inst, 5, 5, 750, 160);

// JSON
{ "type": "text-area", "id": "notesTextArea",
  "rect": { "x": 20, "y": 432, "w": 200, "h": 80 },
  "placeholder": "Multi-line notes...",
  "wordWrap": true,
  "font": { "size": 12 },
  "colors": { "background": { "normal": "#353535FF" }, "border": { "normal": "#606060FF" } },
  "events": { "onTextChanged": "onNotesChanged" } }

4.19.2 控件的方法

方法说明
update() / draw() / handleEvent(Event)帧更新 / 绘制 / 事件（文本输入、Enter 插入 \n、滚动条委托、鼠标定位光标、Ctrl+C/V/X、光标导航）
setRect(SRect)重设尺寸并同步滚动条
setText(string)设置全文（重建行 + 更新滚动条）
insertTextAtCursor(string)光标处插入
insertText(string)插入（在 EditBox 基础上重建行）
deleteSelectedText()删除选中
setScrollY(int) / getScrollY()、setScrollX(int) / getScrollX()垂直 / 水平滚动
scrollToBottom()滚到底部
setWordWrap(bool) / isWordWrap()自动换行开关
setLineHeight(int) / getLineHeight()行高
setScrollBarThickness(float) / getScrollBarThickness()滚动条粗细（默认 16）
setOnTextChangedHandler(OnTextChangedHandler)文本变化回调

4.19.3 控件的属性

属性类型默认值说明
word-wrapBool—自动换行
line-heightInt—行高
scroll-x / scroll-yInt0滚动位置
scrollbar-thicknessFloat16滚动条粗细
继承 EditBox：text / placeholder / password-mode / read-only / font / font-size / alignment 等多类型—见 4.8 EditBox

4.19.4 控件的回调

事件名触发时机负载
text-changed（kEventTextChanged）文本任何变化String（全文）
enter（kEventEnter）按下 Enter（继承 EditBox）无

4.19.6 C++ Binding 样例

Control ta = ui->CreateTextArea(20, 432, 200, 80);
ta.SetString("text", "Hello from TextArea!\nEdit me.");
ta.SetBool("word-wrap", true);
ta.SetCallback(PropertyNames::kEventTextChanged, [](const Event& e) {
    printf("text: %s\n", e.GetTextChanged().c_str());
});

// C++ 核心库
auto ta2 = TextAreaBuilder(nullptr, SRect(750, 360, 200, 100), 2.0f, 2.0f)
    .setText("2x scaled TextArea")
    .setWordWrap(true).setLineHeight(22)
    .setOnTextChanged([](shared_ptr, string text) {
        cout << "TextArea changed" << endl;
    })
    .build();
BENCH->addControl(ta2);
滚动条内置于控件底部 / 右侧，内容超出时自动显示。
