4.14 Menu（菜单：MenuBar / MenuPanel / MenuItem）

菜单系统由三件套组成：MenuBar（顶级菜单栏）、MenuPanel（下拉面板，支持嵌套子菜单）、MenuItem（菜单项，支持 Normal / Separator / SubMenu）。三者均继承 ControlImpl。支持「菜单模式」：点击展开后鼠标移动自动切换顶级菜单。

缩放联动：MenuBar 与下拉面板字号随复合缩放系数重建（Bar 变化经共享字体传播到各面板、嵌套子菜单）。详见 5.6.6。

4.14.1 控件的创建

// C++（三件套 + Builder）
MenuItem(Control* parent, MenuItemType type = MenuItemType::Normal, float xScale = 1.0f, float yScale = 1.0f);
MenuPanel(Control* parent, float xScale = 1.0f, float yScale = 1.0f);
MenuBar(Control* parent, float xScale = 1.0f, float yScale = 1.0f);

auto filePanel = MenuPanelBuilder()
    .addItem(MenuItemBuilder(u8"新建(N)").setShortcut("Ctrl+N").setOnClick(cb).build())
    .addSeparator()
    .build();
auto bar = MenuBarBuilder(BENCH).addMenu(u8"文件(F)", filePanel).build();
BENCH->addControl(bar);

// C ABI（组装顺序：MenuItem → MenuPanel → MenuBar）
UIControlHandle item  = UICornerstone_CreateMenuItem(g_inst, "Open", 0, 1.0f, 1.0f);          // 0=Normal 1=Separator 2=SubMenu
UIControlHandle panel = UICornerstone_CreateMenuPanel(g_inst, 1.0f, 1.0f);
UICornerstone_MenuPanelAddItem(g_inst, panel, item);
UIControlHandle bar   = UICornerstone_CreateMenuBar(g_inst, 0, 0, 800, 32, 1.0f, 1.0f);
UICornerstone_MenuBarAddMenu(g_inst, bar, "File", panel);

4.14.2 控件的属性（C ABI 属性系统）

属性类型说明

4.14.2.1 item 级属性（C ABI，item-id 定位模式）

Menu 的逐项增强属性挂在 MenuPanel 上：先 SetString("item-id", id) 定位目标菜单项，随后 item 级属性作用于该菜单项。MenuItem 自身也支持 SetString("item-id", id) 设置其定位 id（编程式创建时便于后续定位）。

属性类型默认说明
item-idString—定位目标菜单项（在 MenuPanel 上设置后，后续 item 级属性作用于该菜单项）
item-fontEnum继承 MenuPanel逐项字体枚举（如 harmonyos-sans-sc-bold 粗体）
item-font-sizeInt0逐项字号（0 = 继承面板字号；>0 时该行行高 = 字号×item-height-ratio，独立于面板其余行）
item-leading-gapFloat8行前置控件容器与文本之间的间隔（局部 px）
item-leading-controlPtr—行前置控件容器句柄（借用语义，生命周期由调用方保证；类型经 UICornerstone_GetControlType 查询（如 "check-box"），再经通用属性系统操作）。有容器时该行保留 icon 区（宽 = max(各行字体高度, 20)）、不绘制手绘勾选标记（勾选视觉由容器内控件承担）；传 NULL 解除容器

4.14.3 控件的回调

回调 / 事件名触发时机参数
MenuItem::onClick（C ABI 事件 click，JSON 键 onClick）点击普通菜单项（子菜单项展开子菜单）(shared_ptr<MenuItem>) / UIEventCallback(ctl, event, userData)

4.14.4.14 item 增强（行前置控件容器 + 逐 Item 字号/行高）

Menu 二期增强（2026-08 实施）支持：

  • 行前置控件容器：JSON 键 leadingControl（任意控件类型，如 check-box / image）。容器正方形、边长 = 该行字体高度、水平居中于 icon 区、垂直居中于行；面板有容器行时保留 icon 区（宽 = max(各行字体高度, 20)），无容器时 icon 区宽为 0（文本起点 = 左内边距 20，无 gap 预留）。
  • 逐 Item 字体/字号：JSON 键 font（name / size，仅对该项生效；size=0 或缺省继承面板字号）。覆盖项行高 = 该项字号×item-height-ratio（默认 1.6），可形成变行高菜单。
  • 勾选标记：checked（手绘勾，有容器行不绘制；item 勾选状态与容器内 CheckBox 自身状态相互独立）。
// 逐项增强 + 面板级定位（C ABI）
UICornerstone_SetString(g_inst, panel, "item-id", "mToggle");        // 定位项
void* lc = UICornerstone_GetPtr(g_inst, panel, "item-leading-control", NULL); // 取容器
UICornerstone_GetBool(g_inst, lc, "checked", &checked);             // 操作容器
UICornerstone_SetInt(g_inst, panel, "item-font-size", 18);          // 逐项字号
UICornerstone_SetFloat(g_inst, panel, "item-leading-gap", 10);      // 逐项 gap

4.14.5 C++ Binding / 核心库样例

// 核心库（Builder 链式组装）
g_filePanel = MenuPanelBuilder()
    .addItem(MenuItemBuilder(u8"新建(N)")
        .setShortcut("Ctrl+N")
        .setOnClick([](shared_ptr item) { cout << "New file clicked" << endl; })
        .build())
    .addSeparator()
    .addItem(MenuItemBuilder(u8"最近打开的文件")
        .setSubMenu(MenuPanelBuilder()
            .addItem(MenuItemBuilder(u8"file1.txt")
                .setOnClick([](shared_ptr item) { cout << "file1 clicked" << endl; })
                .build())
            .build())
        .build())
    .build();
g_menuBar = MenuBarBuilder(BENCH)
    .addMenu(u8"文件(F)", g_filePanel)
    .build();
BENCH->addControl(g_menuBar);

// Binding：MenuItem 的 caption/checked/shortcut/click 走统一属性系统
Control item = ui->CreateMenuItem("Open", 0);
item.SetString("caption", "Open");
item.SetCallback("click", [](const Event&){ /* ... */ });

4.14.6 C ABI 调用样例

// Menu 三件套：MenuBar + MenuPanel + MenuItem（type: 0=Normal, 1=Separator, 2=SubMenu）
UIControlHandle file = UICornerstone_CreateMenuPanel(g_inst, 1.0f, 1.0f);
UIControlHandle open = UICornerstone_CreateMenuItem(g_inst, "Open", 0, 1.0f, 1.0f);
UICornerstone_MenuPanelAddItem(g_inst, file, open);
UICornerstone_MenuPanelAddSeparator(g_inst, file);
UIControlHandle more = UICornerstone_CreateMenuPanel(g_inst, 1.0f, 1.0f);   // 子菜单面板
UICornerstone_MenuItemSetSubMenu(g_inst, open, more);

UIControlHandle bar = UICornerstone_CreateMenuBar(g_inst, 0, 0, 800, 26, 1.0f, 1.0f);
UICornerstone_MenuBarAddMenu(g_inst, bar, "File", file);

// MenuItem 的 caption / checked / shortcut / click 走统一属性系统
UICornerstone_SetString(g_inst, open, "shortcut", "Ctrl+O");
static void onOpen(UIControlHandle ctl, const UIEventData* ev, void* ud) { }
UICornerstone_SetCallback(g_inst, open, "click", onOpen, NULL);
