4.26 TabControl（选项卡）

TabControl 多页签控件：页签条四方向（上/下/左/右），页面为任意控件子树。两层焦点作用域：Tab 在页内控件循环，Ctrl+Tab 在「页签条 ↔ 页内」间切换。继承链：TabControl → ControlImpl → Control。设计文档见 design/TabControl_Design.md。

4.26.1 控件的创建

// C++
auto tc = TabControlBuilder(nullptr, SRect(120, 80, 560, 240))
              .addTab(u8"主页", page1).addTab(u8"设置", page2).build();

// C ABI
UIControlHandle tc = UICornerstone_CreateTabControl(g_inst, 120, 80, 560, 240, 1, 1);
UICornerstone_TabAddPage(g_inst, tc, u8"主页");

// JSON
{ "type": "tab-control", "rect": {"x":120,"y":80,"w":560,"h":240}, "position": "top",
  "tabs": [ {"title": "主页", "page": {"type": "panel"}} ],
  "events": { "onTabChange": "onTab" } }

属性/字段类型默认值说明

4.26.3 控件的回调 / 事件

事件名触发时机说明
onTabChange页签切换新页索引

4.26.4 键盘导航

页签条获焦：←/→（或竖排 ↑/↓）循环切换、Home/End 首尾；Tab 层内循环（页内控件间 / 页签条+外部）；Ctrl+Tab 层切换（页内 ↔ 页签条）。
