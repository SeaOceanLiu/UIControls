4.10 Label（文本标签）

Label 是文本显示控件：支持单行 / 多行（\n）、9 种对齐、阴影、自动扩展、行高与行距调节，可设为可点击（clickable）。继承链：Label → ControlImpl → Control。

4.10.1 控件的创建

// C++
Label(Control* parent, SRect rect, float xScale = 1.0f, float yScale = 1.0f);
LabelBuilder(parent, SRect(20, 20, 200, 40)).setCaption("Hello").setAlignmentMode(AM_CENTER).build();

// C ABI
UIControlHandle label = UICornerstone_CreateLabel(g_inst, "Hello", 24.0f, 20, 20, 240, 40, 1.0f, 1.0f);

// JSON
{ "type": "label", "id": "titleLabel",
  "rect": { "x": 0, "y": 52, "w": 800, "h": 40 },
  "caption": "Layout Configuration Test",
  "alignment": "center",
  "font": { "name": "HarmonyOS_Sans_SC_Regular", "size": 28 },
  "colors": { "text": { "normal": "#FFFFFFFF" } },
  "shadow": { "enabled": true, "offset": { "x": 2, "y": 2 } } }

4.10.2 控件的属性

属性类型默认值说明
shadowBoolfalse阴影开关
expandBoolfalse自动扩展尺寸
clickableBoolfalse可点击命中
font-sizeInt16字号
line-heightInt字体默认行高行高
line-spacing-ratioFloat默认行距比例行距比例
captionString空文本内容
alignEnummid-left9 值同 EditBox
fontEnumHarmonyOS_Sans_SC_Regular字体名

通用：text / text-shadow（StateColor，可带 .hover/.pressed/.disabled）、visible / enabled / transparent / border-visible。

4.10.3 控件的回调

事件名触发时机负载
click（kEventClick）鼠标左键在文本热区按下 / 抬起（需 setClickable(true)）无
property-changed（kEventPropertyChanged）recreate() 后（字体 / 文本 / 对齐 / 边距等变化）无

4.10.5 C++ Binding 样例

auto label = ui->CreateLabel("Hello", 24.0f, 20, 20, 240, 40);
label.SetString(PropertyNames::kCaption, "Clicked 0");
label.SetEnum(PropertyNames::kAlign, "center");
label.SetBool(PropertyNames::kShadow, true);

// C++ 核心库（多行 + 2x 缩放）
auto l = LabelBuilder(nullptr, SRect(450, 450, 200, 90), 2.0f, 2.0f)
    .setCaption(u8"L15: Mid中\n第一行\n第二行\n第三行")
    .setAlignmentMode(AlignmentMode::AM_CENTER)
    .setEnableExpand(false)
    .setBorderStateColor(redBorder)
    .setId(15)
    .build();
BENCH->addControl(l);

4.10.6 C ABI 调用样例

// fontSize 为创建参数
UIControlHandle lbl = UICornerstone_CreateLabel(g_inst, "Title", 18, 20, 20, 200, 30, 1.0f, 1.0f);

UICornerstone_SetString(g_inst, lbl, "caption", "新标题");
UICornerstone_SetInt(g_inst, lbl, "font-size", 22);
UICornerstone_SetBool(g_inst, lbl, "clickable", 1);

static void onLblClick(UIControlHandle ctl, const UIEventData* ev, void* ud) { }
UICornerstone_SetCallback(g_inst, lbl, "click", onLblClick, NULL);
4.10.7 控件的方法（核心引擎内部 API，点击展开）
本节为核心引擎 C++ 类（include/ 头文件）的公开方法，仅源码级集成（直接使用核心类）可调用。只使用 C ABI / C++ Binding 的用户请按「控件的属性」键名（Set*/Get*）与「控件的回调」事件名（SetCallback）等价操作。
方法说明
getHotRect()文本热区（未缩放）
setCaption(string) / getCaption()文本内容
setFont(FontName) / getFont()字体
setAlignmentMode(AlignmentMode) / getAlignmentMode()对齐（默认 AM_MID_LEFT）
setMargin(Margin) / setFontSize(int) / getFontSize()边距 / 字号（默认 16）
setShadow(bool) / setShadowOffset(SPoint)阴影与偏移
setOnClick(OnClickHandler) / setOnPropertyChanged(OnPropertyChangedHandler)点击（需 clickable）/ 属性变化回调
setLineHeight(int) / getLineHeight() / setLineSpacingRatio(float) / getLineSpacingRatio()行高 / 行距比例
setDebugDraw(bool) / getDebugDraw()调试热区绘制
setEnableExpand(bool) / getEnableExpand()自动扩展尺寸
setClickable(bool)可点击（事件命中）开关
SetFontStyle(int)字体样式（normal/bold/italic/underline/strikethrough）
setXxxProperty / getXxxProperty、setCallbackProperty属性分发
