9.1 声明式 UI 语法速查表

9.1.1 顶层结构

{
  "version": "1.0",
  "viewport": { "width": 1920, "height": 1080 },
  "theme": { "fonts": {...}, "colors": {...} },
  "controls": [ ... ],       // 控件树根数组（必填）
  "dialogs":  [ ... ],       // 弹窗数组（可选）
  "components": { ... },     // 可复用组件模板（可选）
  "layouts": [ ... ]         // 组件实例化（可选）
}

9.1.2 控件通用键

键类型说明
typestring必填。kebab 小写：label / button / edit-box / check-box / combo-box / numeric-up-down / progress-bar / scroll-bar / color-picker / text-area / panel / menu-bar / win-frame / splitter
idstring全局唯一，FindControl 用
rectobject{"x","y","w","h"}；支持百分比字符串 "50%"
scaleobject{"x":1.0,"y":1.0}
visible / enabledbool可见 / 启用
marginobject{"left","top","right","bottom"}
colorsobject状态色：{"background":{"normal","hover","pressed","disabled"}}；键含 background/border/text/textShadow/控件特有（progressColor、titleBar 等）
eventsobject{"onClick":"handlerName"}
childrenarray子控件（容器类型）

9.1.3 颜色格式

"#RGB" | "#RRGGBB" | "#RRGGBBAA" | { "r":255, "g":0, "b":0, "a":128 }

9.1.4 布局引擎

h-flow / v-flow

"layout": { "type": "h-flow", "gap": 4,
             "padding": { "left": 4, "top": 4, "right": 4, "bottom": 4 } }
// 子控件：{ ..., "flowWeight": 1 }  弹性分配；0/缺省=固定

anchor

"layout": { "type": "anchor" }
// 子控件：
{ ..., "anchor": "TOP_RIGHT",
  "anchorOffset": { "left": 10, "top": 10, "right": 0, "bottom": 0 } }
// 锚点值：TOP_LEFT TOP_CENTER TOP_RIGHT MID_LEFT CENTER MID_RIGHT
//         BOTTOM_LEFT BOTTOM_CENTER BOTTOM_RIGHT TOP_STRETCH
//         BOTTOM_STRETCH LEFT_STRETCH RIGHT_STRETCH FILL

grid

"layout": { "type": "grid",
             "columns": ["1fr", "2fr", "100px"],
             "rows": ["30px", "1fr", "auto"] }
// 子控件：{ ..., "grid": { "row":0, "col":1, "rowSpan":1, "colSpan":1 } }
// 尺寸：Fixed "100px" / Flex "1fr" / Auto "auto"

9.1.5 事件引用与注册

// C ABI
UICornerstone_RegisterAction(g_inst, "handleSubmit", cb, NULL);

// C++ Binding
ui->RegisterAction("handleSubmit", [](Control ctl){ /* ... */ });

// 核心库 LayoutParser
parser.registerHandler("handleSubmit", [](shared_ptr<Control> ctl){ /* ... */ });

9.1.6 事件键名 → 控件对照

JSON 事件键适用控件
onClickButton / Label（clickable）/ MenuItem
onTextChanged / onEnterEditBox / TextArea
onCheckChangedCheckBox
onValueChangedProgressBar / Slider / NumericUpDown
onPositionChangedScrollBar
onSelectionChangedComboBox
onColorChangedColorPicker
onClose / onConfirm / onCancelWinFrame / Dialog
onSplitterMovedSplitter

9.1.7 主题

"theme": {
  "fonts": { "default": { "name": "HarmonyOS_Sans_SC_Regular", "size": 16 },
             "button": { "size": 16 } },
  "colors": {
    "background": "#282828FF", "text": "#FFFFFFFF", "border": "#808080FF",
    "button": { "bg": {"normal":"#3C3C3CFF","hover":"#4C4C4CFF","pressed":"#2C2C2CFF"},
                "border": {...}, "text": {...} },
    "checkbox": { "check": "#66BB6AFF", "cross": "#FF5722FF", "boxBorder": "#53535AFF" },
    "progressbar": { "progress": "#66BB6AFF", "track": "#333333FF" }
  }
}

类别：button / label / editbox / textarea / checkbox / progressbar / panel / scrollbar / menubar；应用顺序：Theme 默认 → 公共 colors → 控件专用颜色 → 控件专用字体。

9.1.8 组件与实例化

"components": {
  "SearchBar": {
    "props": { "placeholder": "Search...", "btnText": "Go" },
    "template": {
      "type": "panel", "layout": { "type": "h-flow", "gap": 4 },
      "children": [
        { "type": "edit-box", "id": "$search", "rect": { "w": 200, "h": 30 },
          "placeholder": "$props.placeholder" },
        { "type": "button", "id": "$go", "rect": { "w": 60, "h": 30 },
          "caption": "$props.btnText", "events": { "onClick": "onSearch" } }
      ]
    }
  }
},
"layouts": [
  { "use": "SearchBar", "id": "topSearch",
    "props": { "placeholder": "输入关键词", "btnText": "搜索" },
    "rect": { "x": 20, "y": 20, "w": 300, "h": 40 } }
]

HotReloader reloader("layouts/main.json", rebuildCallback);

reloader.setPollInterval(15);    // 调整间隔
