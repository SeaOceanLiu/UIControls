HandleControl（无 JSON 类型）

核心类专属能力（C ABI 经 UICornerstone_CreateHandleControl(inst, target, ...) 创建，无属性系统键名 / 无布局 JSON 分支）：手柄拖动调整目标控件尺寸。尺寸/颜色/显隐均为 C++ API（setHandleSize / setMinSize / setHandleColor 等，见 4.9 HandleControl）。

ImageButton（类型 image-button，与 button 同语法）

属性 = Button 全量 + 状态图片（normal-image / hover-image / pressed-image，String 只写）；布局 JSON 也可用 "actors": {"normal": path, "hover": ..., "pressed": ...} 声明三态图。
