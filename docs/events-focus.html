3.5 事件

3.5.1 事件分发链路

一条事件从后端到控件的完整路径：

InputBackend::pollEvent（后端原生事件 → Event(EventType + union 数据)）
  → MainWindow::processEvents（WindowClose 退出 / Resize / Moved 处理，其余入队）
  → Bench::inputControl → EventQueue（事件队列）
  → Bench::eventLoopEntry 出队
  → notifyBeforeEventHandlingWatchers（消费则跳过）
  → 控件树逆向 Z 序分派（返回 true 停止传播）
  → notifyAfterEventHandlingWatchers
  → Tab 键由 Bench 拦截转 FocusManager 导航

3.5.2 事件类型（C ABI）

UI_EVENT_NONE, UI_EVENT_MOUSE_MOVE, UI_EVENT_MOUSE_DOWN, UI_EVENT_MOUSE_UP,
UI_EVENT_MOUSE_WHEEL, UI_EVENT_KEY_DOWN, UI_EVENT_KEY_UP, UI_EVENT_TEXT_INPUT,
UI_EVENT_WINDOW_RESIZE, UI_EVENT_WINDOW_CLOSE, UI_EVENT_FOCUS_GAINED, UI_EVENT_FOCUS_LOST

访问宏：UI_EVENT_MOUSE_X(ev)、UI_EVENT_MOUSE_Y(ev)、UI_EVENT_BUTTON(ev)、UI_EVENT_KEY_CODE(ev)、UI_EVENT_KEY_MOD(ev)、UI_EVENT_TEXT(ev)、UI_EVENT_WHEEL_DELTA(ev)、UI_EVENT_RESIZE_W/H(ev)。

控件层的事件统一走属性系统回调（见 3.3 属性系统），事件名常量在 PropertyNames.h：

3.5.5 应用 / 游戏的事件适配（PushUIEvent）

除后端原生输入外，应用/游戏可自行构造事件注入，与原生事件汇合后走同一分派链路（3.5.1 中 EventQueue 之前）：

UICornerstone_PushUIEvent(instance, &ev)   // 跨线程安全：任意线程构造，帧循环消费
  → 注入队列（锁保护，含 auto-quit 定时器线程的场景）
  → MainWindow::processEvents → Bench::inputControl
  → 与后端原生事件同一队列 → 同一分派链路

适用场景：

  • 游戏循环：手柄 / 触摸屏 / 手势层识别出的"虚拟鼠标"事件，转成 UI_EVENT_MOUSE_MOVE / MOUSE_DOWN / MOUSE_UP 注入；
  • 无窗口 / 离屏后端：窗口事件（Resize / Close）与键盘、焦点事件完全由宿主注入；
  • 自定义输入拦截：应用先于后端消费原始输入（视频流、体感），只把需要 UI 处理的部分转发；
  • 自动化 / 录制回放：测试用例回放鼠标序列（与 test_scale_json 等自动化样例同思路）。

事件类型与负载布局见 3.5.2；构造示例（C）：

UIEvent ev;
ev.type = UI_EVENT_MOUSE_DOWN;
UI_EVENT_MOUSE_X(&ev)   = 400.0f;   // data[0..3]
UI_EVENT_MOUSE_Y(&ev)   = 300.0f;   // data[4..7]
UI_EVENT_BUTTON(&ev)    = 0;        // 0=左键
UICornerstone_PushUIEvent(inst, &ev);

注意：UI_EVENT_* 便捷宏同时可读写，负载字段固定偏移即可用 UI_EVENT_BUF_SIZE（128 B）内的任意布局；跨线程注入的事件在帧循环出队时按一次一个分派，不抢占正在处理的回调。

3.6 焦点系统

3.6.1 三件套：Tab 环 / 焦点边界 / 焦点作用域

机制按键行为
Tab 环Tab / Shift+Tab在全部可聚焦控件间循环，跳过不可见/不可用控件；setFocusable(true) 或 setTabIndex(n≥0) 自动注册
焦点边界（FocusBoundary）Tab边界容器（Bench、WinFrame、ColorPicker）内 Tab 仅在直接后代中循环
焦点作用域（scope）Ctrl+Tab / Ctrl+Shift+Tab在各可见边界（Bench + WinFrames）之间轮转

3.6.2 焦点环绘制

获得焦点的控件绘制三层叠加焦点环：黑线（inset 0）+ 白线（inset 1）+ 主题色（inset 2，默认 #4285F4），任何背景上都清晰可见。

  • FocusRingStyle::Solid / Dashed 两种样式；
  • m_focusRingAlwaysVisible 默认 true（鼠标悬停也显示环）；设为 false 则仅键盘 Tab 聚焦时显示；
  • 默认可聚焦控件：EditBox / TextArea / Slider / Button / CheckBox；
  • Button 聚焦时 Enter/Space 触发 onClick，CheckBox 聚焦时 Space 循环三态；
  • 窗口失去系统焦点（FocusLost）自动清除本实例焦点。

3.6.3 多窗口的焦点隔离

多实例/多窗口下每个窗口的焦点相互独立；WinFrame 隐藏时其内部控件被过滤并释放焦点；Ctrl+Tab 在 ...→WinFrameA→WinFrameB→Bench→... 间轮转。
