5 进阶主题

5.1 全面掌握洛蒂动画引擎

LuotiAni 的核心机制：描述 → 烘焙 → 播放。加载 JSON 描述后 prepare() 将每帧合成到离屏画布（帧贴图），播放时仅按毫秒查表绘制。

5.1.1 烘焙与性能

  • 同一动画文件的多个播放器共享烘焙帧数据（LuotiInstance），内存仅一份；
  • 播放速度由真实墙钟毫秒驱动，update() 调用频率不影响动画速度（帧率无关）；
  • 烘焙后可用 getFrameCanvas(frame) 读取合成画布做离屏渲染 / 缩略图。

5.1.2 操作类型语义

类型字段语义
translatetx, ty相对上一关键帧增量累加
scalesx, sy相对上一关键帧累乘
rotateangle, cx, cy角度累加，绕 (cx,cy) 旋转中心
opacityopacity (0~100)百分比覆盖
visiblevisible可见性覆盖

5.1.3 缓动与轨迹

  • easing 写在目标关键帧的操作上，作用于该关键帧段内所有属性的插值：linear / ease-in / ease-out / ease-in-out / quad / sine / cubic / cubic-bezier(x1,y1,x2,y2)；
  • path 仅用于 translate 的段内位置轨迹：bezier（二次/三次贝塞尔）、parabola（初速物理轨迹）、catmull-rom（多点平滑曲线）；控制点相对段起点。

5.1.4 语义陷阱

  • play() 总是复位帧到 0 重播；属性 playing 每次置 1 都是重播（无暂停/继续状态机）；
  • frameRate 不得为 0；第 0 帧关键帧必须存在；
  • animation 属性只写不读；未 prepare 时置 playing=1 会被拒绝（返回 0）；
  • 层类型 shape/text 解析支持但烘焙跳过（无可见输出）。

5.2 多视口与多窗口

UICornerstone 支持单进程多实例 / 多窗口：每个 UIInstance 拥有独立的 UIContext（控件树、事件队列、焦点状态完全隔离）。

5.2.1 后端能力位

// 查询能力位，按需条件化渲染
uint32_t caps = UICornerstone_GetBackendCapabilities(g_inst);
if (caps & UICORN_BACKEND_CAP_MULTI_WINDOW) { /* 可开多窗口 */ }
if (caps & UICORN_BACKEND_CAP_RENDER_TARGET) { /* 可离屏渲染 */ }

raylib 为单窗口架构：多实例下仅首个实例有真实窗口，其余为 headless（Window::isHeadless()），对其渲染会串扰到主实例窗口。多窗口渲染前必须查能力位条件化。

5.4 直接使用 C ABI 接口程序化生成 UI

不用 JSON、不用 C++ 类，纯 C 程序化构建界面（工厂函数 + 属性系统）：

#include "UICornerstoneAPI.h"

static UIInstance g_inst;
static void onBtnClick(UIControlHandle ctl, void* user) {
    UIControlHandle status = UICornerstone_FindControl(g_inst, "status");
    if (status) UICornerstone_SetString(g_inst, status, "caption", "Clicked!");
}

int main(void) {
    g_inst = UICornerstone_CreateInstanceFromPlugin("sdl3", NULL);
    if (!g_inst) return 1;
    UICornerstone_SetViewport(g_inst, 0, 0, 800, 480);
    UICornerstone_RegisterAction(g_inst, "onBtnClick", onBtnClick, NULL);

    // 程序化创建控件（工厂 + 属性）
    UIControlHandle btn = UICornerstone_CreateButton(g_inst, "Click Me", 280, 200, 120, 36);
    UIControlHandle lbl = UICornerstone_CreateLabel(g_inst, "Idle", 16.0f, 60, 260, 200, 30);
    UICornerstone_SetString(g_inst, lbl, "id", "status");
    UICornerstone_SetCallback(g_inst, btn, "click", onBtnClick, NULL);

    // 主循环（无 JSON 依赖）
    while (!UICornerstone_IsQuitRequested(g_inst)) {
        UICornerstone_ProcessEvents(g_inst);
        UICornerstone_Update(g_inst, 1.0 / 60.0);
        UICornerstone_Clear(g_inst);
        UICornerstone_Render(g_inst);
        UICornerstone_Present(g_inst);
    }
    UICornerstone_DestroyInstance(g_inst);
    return 0;
}
